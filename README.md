# EditLens

**What Did Astra’s Edit Actually Do?**

A bilingual research article auditing the explanations behind model-written weight edits through mechanistic interpretability.

Read the article: https://xxlya.github.io/editlens/

## Contents

- `index.html` is the complete English/Chinese article, including interactive figures and embedded illustrations.
- `.nojekyll` serves the page directly through GitHub Pages.

Open `index.html` in a browser to preview locally. No build step or dependencies are required.

## Research

Authors: Xuanqi Zhang, HaoYang Shang, and Xiaoxiao Li.

Experiment code and analysis: https://github.com/assassin808/behavioral-lens-fast

Original study: [Sparks of Weight-Space Programming](https://rikiyat.github.io/blog/weight-space-programming/).
